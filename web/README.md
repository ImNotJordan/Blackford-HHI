# Blackford Benefits Platform (MVP screens)

Next.js App Router UI for the three audiences in the Hyacinth SOW v2.0:

| Path | Audience |
|------|----------|
| `/` | Platform hub |
| `/staff/*` | Blackford CRM |
| `/employer/*` | Employer HR portal |
| `/employee/*` | Benefits enrollment portal |

## Run

```bash
cd web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
